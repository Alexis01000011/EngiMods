Configura tu repositorio con Git

Un lugar seguro para equivocarte: cada cambio queda guardado y siempre puedes volver atrás.

Al terminar podrás

  • Crear un repositorio para tu mod.
  • Guardar tu avance con commits que se entienden.
  • Compartir el enlace con tu tutor.

Antes de escribir la primera línea de tu mod, vale la pena darle un hogar. Git es ese hogar: guarda cada versión de tu trabajo para que puedas experimentar sin miedo.

Crea el repositorio

Abre una terminal en la carpeta de tu mod y escribe:

Terminal
git init
git add .
git commit -m "Inicia el mod con su estructura base"

※ Si ya usas Git en otros proyectos, puedes pasar directo a la siguiente sección.

Consejo: escribe el mensaje como una instrucción, por ejemplo Agrega el comando /saludo. Tu yo del futuro te lo va a agradecer.

Comparte tu avance

Sube el repositorio y pega el enlace en tu entrega. Tu tutor lo revisa en menos de 24 horas y te deja comentarios para seguir mejorando.

Si algo no sale a la primera, es parte de aprender. Escríbele a tu tutor en Discord: para eso estamos.
